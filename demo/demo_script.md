# 麦当劳营养点餐 Agent —— 现场演示脚本

> 给演示者用的"提词器"。照着念 + 敲命令即可，全程约 8 分钟。
> 环境准备：Python 3.9+，先 `cd mcd-nutrition-agent` 进到项目根目录。

---

## 0. 开场白（30 秒）

> "麦当劳一直被贴'高热量'标签，但菜单里其实藏着大量可以健康搭配的选择。
> 这个 Agent 做的事很简单：**你告诉它今天想吃多少热量、想达成什么目标，它用麦当劳官方 160+ 餐品的真实营养数据，自动帮你拼出一份'吃得饱、营养对'的套餐**——从控卡、增肌、控糖，到忌口过滤，最后还能直接下单。"

---

## Demo 1 · 控卡减脂（客户：健身 / 减脂人群）

**话术**："先看最常见的场景——减脂期想吃麦当劳。"

**命令**：
```bash
python cli/main.py --mode calorie --kcal 500
```

**预期输出（要点）**：
```
【控卡减脂】套餐建议（预算 500 千卡）
蜜汁快乐              258 kcal
蜜汁BBQ风味薄皮脆汁鸡-琵琶腿  173 kcal
小杯玉米杯             53 kcal
小杯鲜萃咖啡           15 kcal
─────────────────────────────
合计 499 kcal · 蛋白 43g · 脂肪 19g · 碳水 35g
钠 1271mg · 钙 61mg · 热量利用率 100%
```

**讲解点**：
- "注意看**热量利用率 100%**——它卡在 500 千卡预算线内，一点都没浪费。"
- "而且不是随便凑的，43 克蛋白质、脂肪压到 19 克，是有约束的求解。"

## Demo 2 · 增肌高蛋白（客户：增肌人群）

**话术**："换一个目标——练完要补蛋白。"

**命令**：
```bash
python cli/main.py --mode protein --kcal 700
```

**预期输出（要点）**：
```

果然多肉              478 kcal
蜜汁BBQ风味薄皮脆汁鸡-带骨里脊  152 kcal
小杯玉米杯             53 kcal
大杯鲜萃咖啡           13 kcal
─────────────────────────────
合计 696 kcal · 蛋白 59g · 脂肪 23g · 碳水 57g
```

**讲解点**：
- "**59 克蛋白质**，一顿顶很多人的半日蛋白需求。"
- "引擎会优先挑'蛋白密度高'的餐品，而不是单纯堆热量。"

## Demo 3 · 控糖低 GI（客户：控糖 / 低碳饮食者）

**话术**："第三种人——控糖的。"

**命令**：
```bash

```

**预期输出（要点）**：

- "对需要控糖的人来说，这是真能照着点的答案。"

## Demo 4 · 忌口过滤（客户：忌口 / 过敏人群）

**话术**："更贴心的是——它记得你的忌口。比如这位客户**海鲜过敏**。"

**命令**：
```bash
python cli/main.py --mode calorie --kcal 550 --exclude "鱼"
```

**对比演示（先跑不加过滤，再加 --exclude "鱼"）**：
```
无过滤：蜜汁快乐 + 儿童鱼排堡 + 冰美式小杯 + 大杯鲜萃咖啡   ← 含鱼排堡
忌"鱼"：蜜汁快乐 + 火腿扒麦满分 + 冰美式大杯 + 小杯鲜萃咖啡   ← 鱼排堡被换掉
```

**讲解点**：
- "看到没？**'儿童鱼排堡'被自动替换成了'火腿扒麦满分'**。"
- "支持的忌口：辣、鱼、牛肉、猪肉、鸡肉、蛋、乳糖、海鲜、麸质，全都能过滤。"

## Demo 5 · 全链路下单（客户：想直接吃到的顾客 / 技术评审）

**话术**："最后是杀手锏——不只是给建议，还能**直接下单**。"

**演示方式 A（WorkBuddy 对话，推荐）**：
> 对 WorkBuddy 说："我想吃顿低卡早餐，帮我直接下单，杭州西湖附近"

Agent 会依次完成：
1. `list-nutrition-foods` —— 拿营养数据，拼出套餐
2. `query-nearby-stores` —— 定位门店（示例：麦当劳杭州西湖银泰餐厅）
3. `query-meals` —— 查门店可下单菜单
4. `map_food_to_product` —— 把营养餐品名映射成商品 code
5. `calculate-price` —— 算总价（示例：¥40.5，含堂食/外带两种取餐方式）
6. `create-order` —— 下单（**需用户确认后才执行**）

**演示方式 B（CLI，需配置 MCP 凭证）**：
```bash
MCD_MCP_BASE_URL=... MCD_MCP_AUTH_TOKEN=... \
python cli/main.py --mode calorie --kcal 500 --live --order --city 杭州 --keyword 西湖
```

**讲解点**：
- "整条链路是**真实调用麦当劳 MCP**，不是 mock 数据。"
- "营养 → 门店 → 餐品映射 → 算价 → 下单 → 查订单，全自动闭环。"
- "下单是真实副作用操作，所以**必须先经用户确认**——这是刻意的安全设计。"
