Features

它能做什么

真实 MCP 数据

所有营养结论来自麦当劳官方 MCP（160+ 餐品），非臆测、可复现。

多模式约束求解

贪心 + 局部搜索，自动去重与类别均衡，每类餐品不超过 2 件。

忌口 / 过敏原过滤

辣、鱼、牛肉、猪肉、鸡肉、蛋、乳糖、海鲜、麸质，一键避开。

全天多餐规划

把全天预算按早/午/晚 30/40/30 拆配，跨餐不重复。

完整营养标签

热量、蛋白、脂肪、碳水、钠、钙，六项一次给全。

一键下单闭环

营养 → 门店 → 餐品映射 → 算价 → 下单，全自动串联。
